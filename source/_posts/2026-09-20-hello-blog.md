在社交平台写过很多东西，散落在各个时间线里，过一阵子就再也找不回来。于是决定开一个属于自己的地方。

## 一个不用担心被淹没的地方

平台的问题从来不是"写不了"，而是"写完就沉"。你写了一段话，两小时后它已经被新的内容挤到看不见的位置。而博客不一样，它有一个稳定的地址。

> 写作最大的敌人不是没有灵感，而是知道写出来的东西会迅速消失。

这里会放三类东西：

- **随笔** —— 日常的观察、情绪、零碎的想法
- **小说** —— 偶然想到的故事，慢慢写，不着急写完
- **项目心得** —— 做完一个东西之后，把踩过的坑记下来

## 为什么是静态博客

选型上考虑过很多方案，最后落在"静态生成 + 免费托管"这条路上：

| 方案 | 成本 | 稳定性 | 维护负担 |
| --- | --- | --- | --- |
| 动态博客程序 | 需要服务器 | 一般 | 高 |
| 第三方平台 | 免费 | 受制于人 | 低 |
| 静态博客 | 免费 | 高 | 低 |

纯静态方案在构建期就把 Markdown 渲染成 HTML，运行时不依赖任何后端。这意味着：

1. 不用担心数据库挂了
2. 不用担心哪天服务商改政策
3. 打开速度快，因为就是几个 HTML 文件

## 写作本身应该是简单的

理想状态下，写一篇文章只需要三步：

```bash
# 1. 新建一篇稿子
hexo new "标题"

# 2. 只写 Markdown，不碰排版
vim source/_posts/标题.md

# 3. 一键发布
hexo clean && hexo generate && hexo deploy
```

排版、目录、代码高亮、分类归档这些事，交给工具做。写字的人只管写字。

## 关于这里会写些什么

不打算定太严格的规矩。有想说的就写，没想说的就空着。可能一周三篇，也可能三个月一篇。

如果你恰好路过，欢迎随便看看。要是某一段让你有点共鸣，那就更好了。
